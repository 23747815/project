Data Flow

  1. Prepare: raw monthly BOM files are cleaned into data/bom_weather.csv. The original combiner remains available; the analysis uses its extended counterpart.
  2. Analyse: the analysis calls the existing season-assignment functions, calculates statistics and generates the daily CSV, chart files and HTML report.
  3. Explore: the GUI reads the saved daily CSV, filters by season and displays descriptions, summary values and a temperature graph. Quiz answers are stored in app.py; the report button opens the existing HTML file.
