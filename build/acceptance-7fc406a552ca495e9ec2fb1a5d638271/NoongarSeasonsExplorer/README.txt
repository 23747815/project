NOONGAR SEASONS EXPLORER - WINDOWS DESKTOP APPLICATION

Keep this entire folder together, including the _internal folder.
If received as a ZIP, extract everything before opening the application.
Double-click NoongarSeasonsExplorer.exe. Python and VS Code are not required.

Select a season and click Explore Season for its description, statistics
and daily temperature graph. Quiz opens five multiple-choice questions.
View Full Analysis Report opens the supplied HTML report in your default
browser. Exit closes the application.

The report and CSV are included under _internal/outputs/seasons/.
Do not move just the executable or remove its supporting files.
No raw BOM files or network connection are needed for the explorer or quiz.
External source links in the report require internet access.

This is a Windows x64 build. The application uses approximate month groups
for teaching; weather observations do not represent the full ecological
or cultural knowledge of Noongar seasons.
